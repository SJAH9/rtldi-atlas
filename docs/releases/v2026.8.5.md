## Summary

This release refines the complete web atlas into a consistent, responsive information system and adds conventional project attribution, licensing, and citation guidance.

## Highlights

- Introduces shared primary navigation across all eight web pages, with contextual navigation for data exploration and methods.
- Moves map-specific controls into the map workspace so global navigation remains predictable.
- Applies automatic day/night presentation from the visitor's local clock on every page, including coordinated Plotly map colors.
- Adds direct drill-down links from global lever summaries, Full Data lever headers, and country components to the nine-lever methodology.
- Adds an About page describing the RTLDI Atlas's origins in *Causality and Attraction, Volume I* and its role as a Level 4 Nested Causal Modelling Intervention.
- Documents the Principal Investigator, transparent use of AI and data-science tools, repository license, book rights boundary, and recommended citation.
- Adds field-level Full Data attribution: RTLP, RTLDI, capital-exclusion, potential-GDP, and lever outputs belong to the RTLDI Atlas Project; institutional observations remain attributable to V-Dem; economic and population observations remain attributable to World Bank WDI.
- Adds a restrained project footer linking to About without repeating personal attribution throughout the atlas.
- Verifies 193 Full Data rows, 381 internal links with no missing targets, responsive mobile navigation, zero page-level horizontal overflow, and automatic themes in two browser timezones.
