# RTLDI Atlas v2026.8.8

## Featured Update: Eurozone Report Uses World Bank Eurozone Data

The Eurozone report was originally intended to use the World Bank data for the
euro-area members. Its initial production instead carried over the global
Atlas's US-dollar baselines. This release fulfills the original scope: the
print Eurozone report calculates its monetary results directly from the World
Bank's euro-denominated national observations.

- Uses GDP per capita in current local currency (`NY.GDP.PCAP.CN`), with the
  World Bank's country metadata confirming the currency as Euro for each member.
- Uses matching-year World Bank population (`SP.POP.TOTL`). All 21 members have
  matched 2025 observations in the retrieved source snapshot.
- Recalculates Eurozone totals, national profiles, lever allocations, rankings,
  and historical GDP-based projections in euros. No USD conversion is applied.
- Estimates approximately **EUR 1.285 trillion** in bounded annual capital
  exclusions across the 21 members under the existing model.
- Retains the canonical nine-protection scores, global eta of 0.36, and 25% cap.
- Preserves the World Bank source responses, source update dates, retrieval
  timestamp, country currency metadata, and historical-currency notes in
  `data/raw/wb_eurozone_eur_2026.json`.
- Updates the standalone Eurozone PDF and its module in the complete print
  Atlas, plus the Eurozone CSV and JSON data products.
- Leaves the global USD data, global print profiles, and web Atlas unchanged.
- Corrects the Eurozone QR gateway to open the standalone Eurozone report
  directly at its version-specific release download URL, rather than the
  general web Atlas landing page.

The report covers the 21 members as of 2026. Bulgaria's pre-adoption national
series is retrospectively euro-denominated by the World Bank; the report
discloses this and does not present its model sum as an official historical
euro-area aggregate. The World Bank's regional aggregate alone cannot supply
the member-level RTLP calculations; the report uses the constituent countries.

## Reproduction

```bash
python -m src.generate_eurozone_atlas --refresh-wb
python -m src.generate_atlas_ebook --concat-only
python -m unittest discover -s tests
```

Omit `--refresh-wb` to reproduce the report from the preserved source snapshot.

## Validation

- Eight unit tests pass, including euro units, matched source coverage, source
  isolation, and reconciliation of lever allocations to the Eurozone total.
- The Eurozone report remains 29 pages with all 21 national profiles.
- The complete print Atlas remains 290 pages. Text comparison against the
  previous Atlas confines every changed page to the Eurozone section, physical
  pages 235-263.
- Rendered title, methodology, summary table, national profile, attribution,
  and assembled summary pages were visually checked. The Eurozone report
  contains no dollar-denominated figures.
- The web Atlas and global data products are unchanged.
- The generated QR image was decoded independently and its payload matches the
  version-specific standalone report URL. Both PDFs contain that same clickable
  destination on the Eurozone gateway page.
