# RTLDI Atlas v2026.8.7

## Print Atlas Publication Design Overhaul

This release presents the RTLDI Atlas as a cohesive, print-ready reference publication. The complete ebook is organized for sustained reading, country comparison, source inspection, and movement between print and the deployed Web Atlas.

## Publication Architecture

- 290 A4 pages organized into five parts: global overview, regional summaries, national profiles, Eurozone focus, and evidence/reference matter.
- Continuous physical folios across the assembled volume.
- Deliberate recto/verso alignment with blank versos before major right-hand title pages.
- PDF outline navigation, publication metadata, embedded typography, and print-safe margins.
- One archival profile for each of the 193 United Nations Member States.

## Section Title Gateways

The full-page QR gateways now function as section title pages:

- **UN Regional Summaries**
- **Detailed Nation Profiles**
- **Eurozone Maps and Member Profiles**
- **Glossary and Source Access**

Each gateway includes a high-redundancy QR symbol, a visible fallback URL, and a direct clickable destination.

## Reference and Link Design

- Every visible web URL in the print Atlas is paired with a compact QR code.
- Mini QR rows retain human-readable URLs and clickable PDF annotations.
- Publication record, About, authorship, citations, V-Dem and World Bank source guides, credits, and colophon use the same reference treatment.
- Source ownership clearly distinguishes RTLDI Atlas Project outputs from V-Dem and World Bank observations.

## Editorial and Information Design

- Adds conventional rights, citation, authorship, production disclosure, data attribution, and source-access pages.
- Expands the glossary with causal projection, outer enclosure, feasible set, institutional option value, provenance, robust uncertainty, and print-to-web terms.
- Adds **Causal Projection from Outer Enclosures**, using whistleblower protection to show how a lever can make a beneficial pathway reachable without claiming an immediate or precisely timed response.
- Integrates the Eurozone report after the national profiles and before the evidence/reference section.
- Uses consistent section hierarchy, typography, rules, color, metric cards, lever displays, map framing, and page furniture throughout the volume.

## Reproducibility and Print Validation

- The canonical generator builds the front, regional, national, Eurozone, and back-matter modules before final assembly.
- The build can use checked-in World Bank country-year observations for recent GDP trend text when a live API refresh is unavailable.
- The final artifact contains 193 national profiles and the complete regional and Eurozone sequences.
- Every URL-bearing page contains clickable QR destination annotations.
- Strict PDF parsing, Ghostscript rendering, Python compilation, and repository tests pass.
- Headline publication values remain `$19.29T` in bounded annual capital exclusions and operational `eta=0.36`.
