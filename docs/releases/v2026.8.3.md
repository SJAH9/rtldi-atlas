## Summary

This release brings the print atlas, web atlas, interactive map, full data view, and linked-data export into one cohesive information-design language while preserving the canonical single data pipeline.

## Highlights

- Redesigned print nation pages with stronger country identity, RTLP score badges, nine-lever status strips, cleaner metric hierarchy, and refreshed country-map styling.
- Updated global, regional, and country choropleths with the shared RTLDI atlas R scale, softer ocean and land context, graticules, stronger boundary hierarchy, and small-state locator notes.
- Improved the HTML atlas landing page and Full Data View so they share the same atlas visual language.
- Full Data View now places `RTLP` in the second column and keeps country names linked directly to the interactive country viewer.
- Interactive map now opens country panels directly from `?country=ISO3`, `?iso3=ISO3`, or `#ISO3`.
- RDF/XML linked open data export remains published at `outputs/html-atlas/rtldi_atlas_2026.rdf` and linked from the HTML pages.
